# СІЧ: доба шаблі

**0.3.0 — робочий прототип, 1 листопада 2026 року.** Козацький світ і власна графіка Січі; каталог, вимоги речей, модифікатори та таблиця розвитку перенесені з відкритих довідників Лютеції. Закритий серверний код Carnage не отримано. Непублічні формули бою замінені явно описаним розрахунком прототипу: [PROTOTYPE.md](PROTOTYPE.md).

## Запуск

Потрібен Node.js 22+. Встановлення пакетів або ключі для локальної гри не потрібні.

```sh
node server.mjs
```

Відкрийте `http://127.0.0.1:3000`. У Windows можна запустити `start.cmd`. Збереження — `data/game.json`; інший каталог задається через `GAME_DATA_DIR`, порт — через `PORT`. За замовчуванням нові герої грають за новими правилами. `SICH_RULESET=legacy` залишено для перевірки сумісності попереднього рушія.

## Як почати

1. На площі отримайте припас писаря: 20 досвіду й 5 флоринів.
2. Поговоріть із наставником та отримайте його нагороду в журналі.
3. Розподіліть три початкові очки. У журналі заберіть кольчугу новобранця.
4. Придбайте кастет за 5 флоринів і спорядіть його та кольчугу в інвентарі.
5. Пройдіть початкові тренування. Проміжні пороги досвіду дають флорини й нові очки; перший рівень відкривається на 200 досвіду.
6. Оберіть службу та почніть кампанію. Після сутички кнопка повертає до її прогресу. Між боями можна лікуватися.

## Що працює

- Компактне компонування за наданим концептом: герой і спорядження ліворуч, місто та переходи поряд, великий чат унизу, суперник праворуч під час бою. 20 сторінок і адаптація для телефона.
- 1 365 локалізованих записів у довіднику: ціни, валюти, маса, міцність, вимоги й числові бонуси. Пошук, типи, перевірка доступності та сторінки списку. Особливі речі з неперенесеною дією доступні для огляду, а не для оплати.
- Шість видів зброї: ніж, дубина, меч, сокира, молот і спис; кастети для початку. Бонуси визначають конкретні речі та характеристики, без старих множників п’яти класів.
- Чотири зони удару, захист двох зон, дві стійки, одночасні удари, крит, ухилення, кольоровий літопис і серверний таймер. PvP відкривається з першого рівня; тактика суперника прихована.
- 106 порогів досвіду з проміжними очками й виплатами. Досвід накопичувальний, винагорода за кожен поріг видається один раз. Підтверджена архівними таблицями частина — рівні 0–11 до 29 млн досвіду.
- Флорини та сестерції розділені. Ціни каталогу збережені в сотих частках валюти. Купівля, спорядження, продаж, ремонт, пошук на ринку, посилки й передача конкретних екземплярів працюють на сервері.
- 12 розділів кампанії, 36 сюжетних сутичок, завершення, п’ять міст, каравани, випробування ради, січові рецепти, курені та денні доручення. Їхні власні нагороди та суперники пристосовані до нової прогресії.
- Гостьові герої, реєстрація, вхід, збереження, приватні й загальні канали. Наявні гроші та екземпляри речей не видаляються під час переходу.

## Перевірка

```sh
npm test
npm run test:edge
npm run test:canon-campaign
```

Остання команда проходить навчання та всю кампанію окремо для кожного з шести типів зброї, купує доступне спорядження за зароблені кошти й продає замінені речі. Здоров’я суперників не підміняється; між боями використовується звичайне лікування.

Після зміни джерельних чисел або українських назв:

```sh
npm run canon:build
node scripts/sync-edge-engine.mjs
```

`canon-data.mjs` та `public/canon-data.js` генеруються однаково. Числа перевіряються проти кожного запису `reference/carnage-catalog.json`. Браузер завантажує компактний каталог один раз; регулярні відповіді сервера містять лише динамічні дані та належні героєві речі.

## Хмара

GitHub Pages публікує `public/`; спільний світ обслуговує Supabase Edge Function `sich-api`. Рушій у `supabase/functions/sich-api/engine/` синхронізується з кореневими модулями. Збереження світу використовує порівняння ревізії та повтор запиту при конфлікті. Ідентифікатори запитів запобігають повторній оплаті або видачі нагород.

Ключ сервісної ролі залишається у змінних сервера. Схема авторизації гри з `X-Sich-Session` не змінюється. Перед оновленням робочого сервера зберігається його попередня версія та резервний рядок світу.

## Межі відповідності

Це придатний до гри прототип, а не підтверджена копія закритого сервера 1:1. Професії, повна алхімія, всі руни, тварини, групові режими, зачарування й точні формули КБО ще не відтворені. Міцність і ремонт перенесені; випадкове зношення не вигадувалося. У банку є реальний гаманець двох валют, а не непідтверджена система депозитів.

Джерела, відмінності розрахунку та правила міграції описані в [PROTOTYPE.md](PROTOTYPE.md); первинні числові дані й посилання містяться у [reference/](reference/).

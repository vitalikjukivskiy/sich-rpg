# Січ — структура інтерфейсу Лютеції, Beta 0.2.7

1 листопада 2026 року.

## Розташування

- Вузький вертикальний «Навігатор» ліворуч відкриває карту міст.
- Дворядкова шапка: Інформація, Персонаж, Оновити, Вихід для зареєстрованого героя або Увійти для гостя; нижче сім вкладок у порядку зі зразка.
- Герой зі смугами здоров’я та сил; спорядження розташоване ліворуч, праворуч і під фігурою. Показані всі дев’ять наявних комірок, зокрема печатка. Для неї додано окреме векторне зображення.
- Назва міста, поточна сцена та список переходів мають пропорції, близькі до наданого зразка. Поруч є прямі дії кампанії й лікування. Збережено підказку наступного квестового кроку.
- Унизу широкий чат із чотирма каналами й фактичним списком онлайн. Торговий канал працює на Node та Supabase; приватні повідомлення залишаються доступними лише відправникові й адресатові.
- На телефоні поля перебудовуються, бойові дії залишаються закріпленими, чат відкривається окремою панеллю.

## Вкладки й робочі сторінки

| Вкладка | Сторінки |
| --- | --- |
| Локація | Площа, лікарня, курінь, інформація, карта міст, сторони, рейтинг |
| Інвентар | Спорядження, кузня, персонаж |
| Поєдинки | Арена й активний бій |
| Завдання | Журнал, кампанія, каравани, випробування |
| Банк | Реальний гаманець, крамниця, ринок і наявні торгові дії |
| Навички | Характеристики, вільні очки, похідні показники й перенавчання |
| Налаштування | Час у чаті, збільшений текст, образ персонажа, обліковий запис |

Налаштування відображення зберігаються окремо для кожного персонажа в поточному браузері. Розподіл характеристик і зміна образу використовують чинні серверні дії; під час активного бою недоступні дії заблоковані.

## Перевірки

- 89 тестів рушія, HTTP, навігації, персональних налаштувань і форматування літопису.
- Edge integration: торговий канал доступний іншому гравцеві; приватне повідомлення доступне лише двом учасникам. Перевірені CAS, повторні запити та чинні бойові сценарії.
- 252 перевірки: 20 сторінок нового й розвиненого героя та PvE/PvP на шести розмірах екрана. Перевірені активна вкладка, переходи, зображення, горизонтальне переповнення, таймер, двозонні блоки та видимий літопис.
- Окремо перевірені точний порядок семи вкладок, дев’ять комірок, фінансовий огляд, навички, збереження налаштувань після перезавантаження та справжній обмін у торговому каналі.
- Збережені кольори літопису, бойові механіки та повернення до прогресу завдання з попереднього релізу.

Кеш клієнта: `20261101-lutecia2`. Серверна збірка: `beta-0.2.7-20261101`. Серверне оновлення додає публічний торговий канал; схема даних, бойові формули, баланси й предмети гравців не мігрують.

Додаткова перевірка відображення: нижні комірки спорядження обмежені висотою свого рядка, тому не перекривають характеристики. Атласи персонажів і речей завантажуються заздалегідь; SVG показує зображення після його декодування, щоб повільне з’єднання не створювало враження обрізаної фігури. Повторні 252 перевірки контролюють межі кожної комірки й помилки атласів; порушень не виявлено. 89 тестів пройшли.

Довідник і відмінності числових механік: `CARNAGE-REFERENCE.md`. Новий інтерфейс не видається за повну числову копію поточного сервера Carnage.

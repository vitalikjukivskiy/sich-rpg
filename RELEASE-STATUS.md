# Статус релізу Beta 0.2.1

Підготовлено 28 жовтня 2026 року.

- 75/75 тестів рушія та HTTP проходять.
- Edge-інтеграція, конкурентні запити, повторні дії, приховані ходи та тайм-аути перевірені.
- 220 000 контрольних дуелей; еталонні та стандартні різнорівневі сценарії відповідають контрольним межам.
- Клієнт перевірений у Chromium на 1440×900, 1366×768, 1280×800 та 390×844.
- Резервні копії попереднього коду й Edge Function збережені.

## Публікація

Оновлення живої функції Supabase `sich-api` було відхилене автоматичною перевіркою дозволів. Причина: потрібна окрема явна згода користувача на заміну робочого сервера, що може вплинути на поточних гравців.

Сервер та опублікована головна гілка не змінені. Код готується в окремій гілці/PR для перегляду. Після дозволу потрібно: розгорнути `sich-api`, злити зміни клієнта, дочекатися GitHub Pages і перевірити обидві частини онлайн.
